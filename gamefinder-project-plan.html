01기획 배경

게임의 종류와 플랫폼이 많아지면서 어떤 게임을 해야 할지 찾는 과정이 점점 복잡해지고 있습니다. Steam, PlayStation, Xbox, Nintendo 등 플랫폼별로 게임 정보가 나뉘어 있고, 인기 게임이나 신작을 확인하려면 여러 사이트를 찾아봐야 합니다. GameFinder는 다양한 플랫폼의 인기 게임과 최신 게임을 한곳에서 확인하고, 장르와 플랫폼으로 원하는 게임을 쉽게 찾을 수 있도록 만들고자 합니다. 추가로 AI를 활용해 사람의 취향을 분석하고 개인에게 맞는 게임을 추천해주는 기능을 제공합니다.

05AI 추천 서비스

NextRez처럼 사용자의 취향에 맞춰 게임을 추천해 주는 AI 서비스를 GameFinder의 핵심 기능으로 구현합니다. AI가 말로만 추천하는 것이 아니라, 실제 게임 데이터와 연결된 결과를 보여주는 것이 목표입니다.

1. 취향 입력

좋아하는 게임, 선호 장르·플랫폼, 플레이 성향(스토리/경쟁/힐링 등)을 선택하거나 자유롭게 입력

2. 취향 분석

AI가 입력 내용을 분석해 장르, 태그, 분위기 같은 검색 가능한 취향 조건으로 정리

3. 게임 데이터 매칭

정리된 조건으로 외부 게임 데이터(RAWG, IGDB 등)에서 실제 존재하는 게임만 골라 후보 구성

4. 추천 결과

게임 카드와 함께 “왜 이 게임을 추천하는지” 이유를 표시하고, 게임 상세 화면으로 연결

AI가 존재하지 않는 게임을 만들어내지 않도록, 추천 후보는 반드시 게임 데이터에서 가져온 목록 안에서만 선택하게 설계합니다. 찜·추천 기록 저장은 이후 단계에서 확장합니다.

06필요한 화면

  • 메인 — 인기 게임, 최신 게임, AI 추천을 간단하게 보여주는 첫 화면
  • 인기 순위 — 글로벌 인기 게임을 1위부터 최대 1000위까지 확인하는 화면
  • 신작 — 최근 출시된 게임을 확인하는 화면
  • 게임 찾기 — 플랫폼, 장르, 태그 조건으로 게임을 검색하는 화면
  • 게임 상세 — 선택한 게임의 자세한 정보를 확인하는 화면
  • AI 추천 — 취향을 입력하고 개인화된 게임 추천을 받는 화면
검색 조건은 서로 다른 그룹끼리는 AND, 같은 그룹 안에서는 OR 방식으로 동작하도록 설계합니다. 예: (PC OR PS5) AND (RPG OR Action) AND Open World

07얻고 싶은 것

단순히 게임 정보를 보여주는 사이트를 만드는 것이 아니라, 외부 게임 데이터를 활용하고 검색·필터·순위 기능을 구현하면서 실제 서비스 형태의 웹사이트를 만드는 것이 목표입니다. 또한 AI를 단순 채팅 기능으로 사용하는 것이 아니라 사람의 취향을 분석하고 실제 게임 데이터와 연결하여 추천하는 기능을 구현해보고 싶습니다.

최종 목표는 “지금 어떤 게임이 인기 있는지 확인하고, 내가 좋아할 게임까지 쉽게 찾을 수 있는 웹서비스”를 완성하는 것입니다.
