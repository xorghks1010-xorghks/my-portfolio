FUNCTION SPEC

GameFinder 기능 + 화면 정의서

Claude Code가 바로 구현할 수 있도록 기능 흐름과 화면 구성을 정리한 문서

관련 문서: ← 프로젝트 기획서

01. 사용자 시나리오

01-1. 메인에서 핵심 기능을 선택하는 사용자

처음 들어온 사용자가 메인 Hero 슬라이드에서 AI 추천, 할인 게임, 인기 순위를 확인하고, 관심 있는 배너를 눌러 해당 기능으로 이동합니다.

01-2. 조건을 조합해 원하는 게임을 찾는 사용자

특정 플랫폼이나 장르의 게임을 찾고 싶은 사용자가 게임 찾기 화면에서 플랫폼, 장르, 태그를 선택하고 조건에 맞는 게임 목록을 확인합니다.

01-3. 인기 게임과 신작을 둘러보는 사용자

요즘 인기 있는 게임이나 새로 출시된 게임이 궁금한 사용자가 인기 순위 또는 신작 페이지에서 목록을 확인하고, 관심 있는 게임의 상세 화면으로 이동합니다.

01-4. 할인 중인 게임을 찾는 사용자

게임을 저렴하게 구매하고 싶은 사용자가 할인 게임 페이지에서 Steam, Epic Games 등 원하는 스토어를 선택하고 할인율과 가격을 비교합니다.

01-5. AI에게 게임을 추천받는 사용자

무슨 게임을 할지 고민하는 사용자가 플레이 가능한 플랫폼과 좋아했던 게임 3개 이상을 선택하면, AI가 취향을 분석해 실제 GameFinder 데이터 안에서 게임 5개를 추천합니다.

01-6. 추천 게임을 자세히 확인하는 사용자

AI 추천 결과에서 적합도와 추천 이유를 확인한 사용자가 마음에 드는 게임을 선택해 장르, 플랫폼, 평점, 스크린샷, 스토어별 가격과 할인 정보를 확인합니다.

02. 기능별 상세

공통 헤더 / 검색

  • 목적: 모든 화면에서 주요 메뉴와 게임 검색 기능을 동일하게 제공합니다.
  • 어느 화면: 전체 페이지 공통
  • 사용자 행동: 게임 찾기 / 인기 순위 / 신작 / 할인 게임 / AI 추천 메뉴 클릭, 또는 검색창에 게임명 입력
  • 입력값: 게임명 검색어
  • 처리: 메뉴 클릭 시 해당 페이지로 이동합니다. 검색 시 게임명 기준으로 검색 결과를 조회합니다.
  • 성공 결과: 해당 페이지 또는 검색 결과 목록을 표시합니다.
  • 예외 상황: 검색 결과가 없으면 검색 결과가 없습니다.를 표시합니다.
  • 우선순위: 필수

메인 Hero 슬라이드 배너

  • 목적: 메인 페이지 상단에서 핵심 기능을 한 영역 안에서 순차적으로 소개하고 각 기능 페이지로 연결합니다.
  • 어느 화면: 메인 페이지 최상단 Hero 영역

슬라이드 구성

  1. AI 추천

    • 문구: 내 취향에 맞는 게임을 찾아보세요
    • 이동: AI 추천 페이지

  2. 할인 게임

    • 문구: 지금 할인 중인 게임을 확인하세요
    • 이동: 할인 게임 페이지

  3. 인기 순위

    • 문구: 요즘 가장 인기 있는 게임은?
    • 이동: 인기 순위 페이지
  • 사용자 행동: 배너 버튼 클릭 / 좌우 화살표 클릭 / 하단 인디케이터 클릭 / 마우스로 좌우 드래그 / 모바일에서 좌우 스와이프
  • 처리: 사용자 조작에 따라 이전 또는 다음 슬라이드로 이동합니다. 각 슬라이드 버튼은 지정된 페이지로 이동합니다.
  • 자동 동작: 약 5초 간격으로 다음 슬라이드로 자동 전환합니다.
  • 드래그 동작: 마우스 왼쪽 버튼을 누른 채 좌우로 일정 거리 이상 끌면 이전/다음 슬라이드로 이동합니다. 짧은 드래그는 원래 위치로 복귀합니다.
  • 스와이프 동작: 모바일/태블릿에서 좌우 터치 스와이프로 이전/다음 슬라이드로 전환합니다.
  • 자동재생 정지: 마우스 오버, 드래그 중, 터치 중에는 자동 슬라이드를 일시정지합니다.
  • 순환: 마지막 슬라이드 다음에는 첫 번째 슬라이드로 자연스럽게 이동합니다.
  • 전환: 슬라이드는 좌우로 부드럽게 이동하며 전환 시간은 약 300~500ms로 합니다.
  • 성공 결과: 현재 슬라이드가 명확하게 보이고 버튼·화살표·인디케이터·드래그/스와이프가 정상 동작합니다.
  • 예외 상황: 자동 전환이 실패해도 사용자가 직접 좌우 버튼과 드래그로 이동할 수 있어야 합니다.
  • 우선순위: 필수

메인 페이지

  • 목적: 사이트의 핵심 기능을 한 화면에서 빠르게 확인하게 합니다.
  • 어느 화면: 메인
  • 구성: Hero 슬라이드 / 글로벌 인기 TOP 5 / 최신 게임 5개 / 할인 게임 5개 / 플랫폼·장르 탐색 / Footer
  • 사용자 행동: 게임 카드 클릭 / 더보기 / 플랫폼·장르 선택 / Hero 슬라이드 이용
  • 성공 결과: 각 섹션의 대표 콘텐츠를 간단하게 표시하고 상세 페이지로 이동할 수 있습니다.
  • 예외 상황: 특정 섹션의 데이터 조회 실패 시 해당 섹션에 재시도 버튼을 표시합니다.
  • 우선순위: 필수

게임 찾기

  • 목적: 플랫폼, 장르, 태그를 조합해서 원하는 게임을 찾습니다.
  • 어느 화면: 게임 찾기
  • 사용자 행동: 플랫폼 / 장르 / 태그 체크, 정렬 조건 선택, 검색어 입력
  • 입력값: platform[], genre[], tag[], keyword, sort
  • 처리: 같은 그룹은 OR, 서로 다른 그룹은 AND로 검색합니다.
  • 검색 예시: (PC OR PS5) AND (RPG OR Action) AND (Open World)
  • 성공 결과: 조건에 맞는 게임을 카드 그리드로 표시합니다.
  • 예외 상황: 검색 결과가 0건이면 빈 결과 안내와 필터 초기화 버튼을 표시합니다.
  • 우선순위: 필수

글로벌 인기 순위

  • 목적: 현재 인기 있는 게임을 순위 형태로 최대 1000위까지 확인합니다.
  • 어느 화면: 인기 순위
  • 사용자 행동: 플랫폼·장르 필터 선택, 페이지 이동
  • 입력값: platform, genre, page, size=100
  • 처리: 인기 점수 기준 내림차순 정렬 후 100개 단위로 조회합니다.
  • 성공 결과: 순위 / 게임 이미지 / 게임명 / 장르 / 플랫폼 / 평점 / 순위 변동을 표시합니다.
  • 예외 상황: 해당 조건의 데이터가 없으면 빈 결과를 표시합니다.
  • 우선순위: 필수

최신 게임

  • 목적: 최근 출시된 게임을 출시일 기준으로 확인합니다.
  • 어느 화면: 신작
  • 사용자 행동: 플랫폼·장르 필터 선택, 페이지 이동
  • 처리: releaseDate DESC 기준으로 정렬합니다.
  • 성공 결과: 최신 출시 게임 목록을 표시합니다.
  • 예외 상황: 출시일 정보가 없는 게임은 최신 순위에서 제외하거나 별도로 처리합니다.
  • 우선순위: 필수

할인 게임

  • 목적: 여러 게임 스토어에서 현재 할인 중인 게임을 한 화면에서 확인합니다.
  • 어느 화면: 할인 게임
  • 스토어: Steam / Epic Games / 기타 연동 가능한 스토어
  • 사용자 행동: 스토어 선택 / 할인율 정렬 / 가격 정렬 / 게임 선택
  • 입력값: store[], sort, page, size
  • 처리: 현재 할인 중인 게임을 조회하고 할인율·가격 조건에 따라 정렬합니다.
  • 성공 결과: 게임 이미지 / 게임명 / 스토어 / 정가 / 할인가 / 할인율 / 스토어 이동 버튼을 표시합니다.
  • 예외 상황: 가격 데이터가 없으면 가격 정보 없음을 표시하고, 할인 종료 시 목록에서 제외합니다.
  • 메인 노출: 메인 페이지에는 할인 게임 TOP 5만 노출하고 전체보기를 통해 할인 게임 페이지로 이동합니다.
  • 우선순위: 필수

게임 상세 — 가격 / 할인 정보

  • 목적: 게임 상세 화면에서 여러 스토어의 현재 가격과 할인 정보를 비교합니다.
  • 어느 화면: 게임 상세
  • 성공 결과: 스토어별 정가 / 할인가 / 할인율 / 최저가 스토어 / 스토어 이동 버튼을 표시합니다.
  • 예외 상황: 판매하지 않는 스토어는 표시하지 않거나 판매 없음을 표시합니다.
  • 우선순위: 필수

게임 상세

  • 목적: 선택한 게임의 핵심 정보를 한 화면에서 확인합니다.
  • 어느 화면: 게임 상세
  • 사용자 행동: 게임 카드 또는 리스트 항목 클릭
  • 입력값: gameId
  • 성공 결과: 게임명 / 커버 / 소개 / 출시일 / 개발사 / 장르 / 플랫폼 / 태그 / 평점 / 가격·할인 / 스크린샷 / 비슷한 게임을 표시합니다.
  • 예외 상황: 존재하지 않는 gameId 접근 시 404 화면을 표시합니다.
  • 우선순위: 필수

AI 추천 — STEP 1 플랫폼 선택

  • 목적: 사용자가 실제로 플레이 가능한 플랫폼을 먼저 제한합니다.
  • 사용자 행동: PC / PS5 / Xbox Series X|S / Nintendo Switch 2 중 하나 이상 선택
  • 성공 결과: 선택 카드는 파란색 테두리와 체크 표시를 보여주고 다음 버튼을 활성화합니다.
  • 예외 상황: 플랫폼 미선택 시 다음 버튼을 비활성화합니다.
  • 우선순위: 필수

AI 추천 — STEP 2 좋아하는 게임 선택

  • 목적: 사용자의 취향을 파악하기 위한 기준 게임을 수집합니다.
  • 사용자 행동: 검색창에서 게임 검색 후 3~10개 선택, 선택 게임 삭제 가능
  • 성공 결과: 선택 게임 카드와 선택 수(예: 3 / 10)를 표시하고 3개 이상 선택 시 추천 버튼을 활성화합니다.
  • 예외 상황: 3개 미만이면 추천 실행 불가 / 10개 초과 선택 불가
  • 참고 UX: NextRez처럼 검색 → 선택 → 선택 목록 확인 → 추천 실행의 단순한 흐름을 참고합니다.
  • 우선순위: 필수

AI 추천 — STEP 3 분석

  • 목적: 선택 게임과 플랫폼을 바탕으로 실제 게임 데이터에서 후보를 만든 뒤 AI에게 전달합니다.
  • 처리 흐름:
    1. 선택 게임의 장르/태그 분석
    2. 플랫폼 필터 적용
    3. DB에서 후보 20~30개 추출
    4. AI 호출
  • 성공 결과: 추천 결과 5개 생성
  • 예외 상황: AI 오류 시 1회 재시도 후 실패하면 DB 기반 대체 추천 또는 재시도 안내
  • 우선순위: 필수

AI 추천 — STEP 4 추천 결과

  • 목적: AI가 선택한 최종 추천 게임 5개와 추천 이유를 보여줍니다.
  • 처리: AI는 DB 후보 중 5개를 선택하고 gameId, score, reason만 반환합니다.
  • 성공 결과: 순위 / 게임 이미지 / 게임명 / 추천 적합도 / 장르 / 플랫폼 / 추천 이유 / 상세보기 버튼을 표시합니다.
  • 예외 상황: 추천 결과가 5개 미만이면 가능한 결과만 노출하고 안내 문구를 표시합니다.
  • 중요: AI가 게임명을 직접 생성하지 않습니다. 실제 게임 정보는 gameId 기준으로 DB에서 조회합니다.
  • 우선순위: 필수

06. 분류 규칙

Genre

게임의 큰 장르를 의미합니다.

예:

  • RPG
  • Action
  • FPS
  • Adventure
  • Strategy
  • Simulation
  • Sports
  • Racing
  • Puzzle
  • Horror

Tag

게임의 세부 특징을 의미합니다.

예:

  • Open World
  • Souls-like
  • Farming
  • Roguelike
  • Single Player
  • Multiplayer
  • Co-op
  • Story Rich

Open World는 Genre가 아니라 Tag로 처리합니다.

07. 구현 시 지켜야 할 규칙

  1. 기획서와 이 plan.md를 최우선 기준으로 구현합니다.
  2. 문서에 없는 기능을 임의로 추가하지 않습니다.
  3. Hero 슬라이드는 버튼, 인디케이터, 마우스 드래그, 터치 스와이프를 모두 지원합니다.
  4. Hero 자동 전환은 사용자가 직접 조작할 때 일시정지합니다.
  5. 게임 정보와 할인 정보는 역할을 분리해 관리합니다.
  6. 모든 데이터 조회 화면에 Loading / Empty / Error / Retry 상태를 구현합니다.
  7. AI는 DB 후보 중에서만 추천하며 실제 게임 정보를 임의 생성하지 않습니다.
  8. Genre와 Tag를 구분하고 Open World는 Tag로 처리합니다.
  9. 같은 필터 그룹은 OR, 다른 그룹끼리는 AND로 처리합니다.
  10. 반복 UI는 공통 컴포넌트로 분리합니다.
